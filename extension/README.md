# FallbackLyrics - Chrome extension (web build)

Локальная сборка аддона как расширения Chrome (Manifest V3) для веб-версии Яндекс Музыки. Не релиз, только для теста.

## Установка

1. Открой `chrome://extensions`.
2. Включи "Режим разработчика" (Developer mode).
3. "Загрузить распакованное" (Load unpacked) и выбери эту папку (`extension`).
4. Открой https://music.yandex.ru и включи любой трек.

После правок файлов нажми "Обновить" на карточке расширения и перезагрузи вкладку Music.

## Что внутри

- `manifest.json` - MV3, content script на домены music.yandex.* и host permissions на источники текста.
- `bridge.js` - проксирует кросс-доменные запросы через background, чтобы обойти CORS.
- `background.js` - service worker, реально выполняет fetch и отдаёт текст обратно в content script.
- `content.js` - логика аддона (копия `script.js`) с правками под веб:
  - фолбэк-селекторы для плеер-бара и кнопки текста;
  - определение трека через `navigator.mediaSession.metadata`, если разметка не совпала;
  - плавающая кнопка "Текст" справа снизу, если нативная кнопка текста не найдена.
- `style.css` - стили дока, без изменений.

## Как пользоваться

- Если у трека нет родного текста, нативная кнопка текста обычно disabled. Аддон делает её активной, и по клику открывает свой док с альтернативным текстом.
- Если родной текст есть, зажми кнопку текста примерно на 800 мс - откроется альтернативный.
- Если нативной кнопки нет вообще, справа снизу появляется кнопка "Текст".
- Источники переключаются кнопками в доке, плюс вкладка своего текста.
- Кэш и свой текст лежат в `localStorage` страницы Music (ключи `ps-fallback-lyrics-cache-v1` и `ps-fallback-custom-lyrics-v1`).

## Ограничения теста

- Внешние источники ходят через service worker: если источник отдаёт 403/капчу, док просто перейдёт к следующему.
- Селекторы Яндекс Музыки могут отличаться от десктопного клиента - тогда сработают фолбэки (медиасессия + плавающая кнопка).
- Настройка `longPressMs` пока не вынесена в UI, зашита 800 мс.
- Иконки урезаны из `Assets/logo.png`.
